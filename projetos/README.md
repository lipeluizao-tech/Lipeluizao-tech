# Catálogo de projetos

## Ferramenta implementada neste repositório

- [Notificador Telegram de tarefas](telegram-notificador.md): script Python para executar comandos locais com limite de tempo e enviar o estado final. Testes locais executados; ativação no Telegram do usuário pendente.

As propostas abaixo são um ponto de partida e não representam entregas concluídas.

## Como cadastrar uma entrega real

1. Crie o repositório do projeto e um README com execução e testes.
2. Copie `templates/projeto.md` para `projetos/nome-do-projeto.md` e preencha dados reais.
3. Adicione aqui o link da ficha e do repositório, com estado: em desenvolvimento, publicado ou pausado.
4. Registre demonstração e resultados dos testes, incluindo limitações.
5. Atualize a ficha quando uma entrega mudar o comportamento do projeto.

Prefira repositórios separados para os aplicativos; este funciona como índice do perfil e registro de evolução.
